# データ収録ポリシー

## 受け入れ条件

候補は次の条件をすべて満たす必要があります。

1. 行政機関、道路管理者、交通機関、観光局、研究・自然保護機関など、責任主体を確認できる公開元である。
2. 一般利用者向けに意図して公開された固定カメラまたは公式カメラ一覧である。
3. HTTPS でアクセスでき、認証回避、秘密の URL、資格情報、リバースエンジニアリングを必要としない。
4. 原典、利用条件、必要な帰属表示を記録できる。
5. 公開目的が道路・気象・災害・観光・自然観察などで、特定個人の追跡を目的としない。
6. 埋め込みやデータ利用が禁止されていない。判断できない場合は外部リンクだけにするか、収録しない。

## 受け入れないもの

- 個人宅、学校内部、病院内部、避難所、保護施設など、プライバシーや安全上のリスクが高い場所
- 無断配信、侵害されたカメラ、検索エンジンで偶然見つかった管理画面
- ログイン、Cookie、トークン、Referer 偽装、IP 制限回避などを要する映像
- PTZ、ズーム、音声送信、録画取得などのカメラ操作
- 顔、車両番号、服装、移動経路などを抽出・照合する機能
- 履歴映像の収集、連続スクレイピング、公開元の負荷を増やす自動巡回
- 飛行・撮影・配信の権限を確認できないドローン映像

## 状態表示

`HLS` は URL の形式、`更新画像` は公開元の提供形式を表します。接続可否を常時監視する「オンライン」表示ではありません。停止、季節休止、地域制限、公開元の変更があり得ます。

## 削除基準

公開停止、利用条件違反、位置誤り、所有者からの正当な要請、プライバシー・安全上の問題が確認された項目は削除します。映像そのものをリポジトリに保存していないため、カタログ参照を削除すれば以後のサイト表示から除外できます。
