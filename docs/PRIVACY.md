# プライバシー設計

## このサイトが保存するもの

- お気に入りのカメラ ID: ブラウザの `localStorage` のみ

サーバー側アカウント、Cookie、広告 SDK、アクセス解析 SDK、独自ログ収集はありません。GitHub Pages や外部公開元には、それぞれの通常の配信ログが残る可能性があります。

## 現在地

「近い順」を押した時だけブラウザ標準の位置情報許可を求めます。座標はメモリ上で距離計算と地図移動に使い、ネットワーク送信、永続保存、URL への付与を行いません。ページを閉じると並べ替え状態は失われます。

## 外部画像・映像

初期表示ではカタログと地図タイルだけを取得します。カメラ詳細の「読み込む」を押すまで、Fintraffic や Caltrans のメディアホストへ接続しません。読み込み後は公開元が IP アドレス、User-Agent、Referer など通常の HTTP 情報を受け取る可能性があります。

このアプリは画像・映像をプロキシ、録画、解析、再配布しません。

## お気に入りの削除

ブラウザのサイトデータを削除するか、保存済み項目の星をもう一度押すと削除できます。
